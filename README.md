# Authenticated Transfer (AT) IETF Drafts

An IETF working group has been formed for the Authenticated Transfer Protocol. More details on the scope of work can be found in the [working group charter](https://datatracker.ietf.org/wg/atp/about/)

This repo is no longer in use and current work is being undertaken in the [ietf-wg-atp](https://github.com/ietf-wg-atp/drafts) repo.
